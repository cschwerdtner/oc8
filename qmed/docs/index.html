Wie pflege ich die Doku?

  1. Markdown bearbeiten oder neu anlegen unter docs/<bereich>/<name>.md (z. B. docs/02_technical/…).
  2. Erste # Überschrift wird zum Kachel-Titel, der erste Absatz zur Kurzbeschreibung — keine Metadaten von Hand nötig.
  3. Welche Dateien aufgenommen werden und in welchem Bereich sie landen, steht in .doc-wiki.json (Bereich = categories[]).
  4. HTML & Index werden generiert — der pre-commit-Hook ruft scripts/doc_wiki.py build; index.html und die Seiten-HTMLs nie von Hand editieren.
